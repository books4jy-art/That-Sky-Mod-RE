Unofficial That Sky Mod update for Sky 0.35.2 (Android, Canvas / Sky Modloader).

- **Skip Spirit Tree Prerequisites** (Unlocks) now says what it can and can't do: it lets you select any node,
  but the server refuses buying a node out of order or above your tier (the game then shows "game data
  corrupted"; restart the game to clear it).
- Also in this update (0.26.2–0.26.3): server features work again (Wing Light collect/refresh and the rest),
  Relog works again, Auto Burn Plants / Dyes turn on again, the Auto Wax Tools run turns on the burn switches.
