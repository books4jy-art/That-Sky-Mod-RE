Unofficial That Sky Mod update for Sky 0.35.2 (Android, Canvas / Sky Modloader).

- **New: Change Server** (Teleport → Dynamic): goes Home, then back to the same level and the spot you stood on,
  so you land on a different game server.
- **New: Apartment Hopping** (Teleport → Dynamic): with it on, Change Server can take you through other players'
  apartments instead of sending you back to your own.
- **Skip Spirit Tree Prerequisites** (Unlocks) now says what it can and can't do: you can select any node, but
  the server refuses buying a node out of order or above your tier (the game then shows "game data corrupted";
  restart the game to clear it).
- Also since 0.26.1: server features work again (Wing Light collect/refresh and the rest), Relog works again,
  Auto Burn Plants / Dyes turn on again, and the Auto Wax Tools run turns on the burn switches.

That Sky Mod is made by XeTrinityz and the TSM team. Unofficial build; see the README for credits.
