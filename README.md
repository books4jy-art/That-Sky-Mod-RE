# That-Sky-Mod-RE
Not made by me! All credits go to the original TSM makers

> **That Sky Mod is made by [XeTrinityz](https://github.com/XeTrinityz) and the TSM team.**
> These are unofficial builds that keep the mod running on newer Sky versions. They are not
> made or supported by the original authors. See [Credits](#credits).

Builds of the unofficial That Sky Mod (TSM) update for **Sky: Children of the Light 0.35.2** on Android
(arm64-v8a), for **Canvas / Sky Modloader**.

## Install

1. Download `libTSM.so` from the [latest release](../../releases/latest).
2. Import it into Canvas as a mod and start the game.

## Updates

Canvas updates the mod from this repository: tap the mod's update button in Canvas and it downloads
the newest release when its version is higher than the installed one.

Each release is published automatically when `libTSM.so` and `VERSION` are updated on `main`.
